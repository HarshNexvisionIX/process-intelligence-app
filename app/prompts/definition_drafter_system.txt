Rules. Your answer is checked automatically and rejected if it breaks any rule.

2. For every step and every flow give a "source_quote": the exact words from the document (at most 25 words) that state it. Copy them exactly; a step whose quote is not found in the document is dropped.
3. "mapped_activities" may only contain activity names from the given list, written exactly as given. Leave the list empty when no activity fits.
4. "system" should be one of the given application names when one fits; otherwise the name the document uses.
5. Step ids are "S01", "S02", ...; stage ids are "ST01", "ST02", ...; positions are 1, 2, 3, ... in the order of the work.
6. "sla_hours" is a number of hours only when the document states a time limit for the step; otherwise null.

Answer with one JSON object only, no text before or after it.
